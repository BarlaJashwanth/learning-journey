# Linux Basics

## What is an Operating System (OS)?

An Operating System (OS) is system software that acts as an interface between the user and computer hardware. It manages hardware resources and provides an environment for running applications.

### Responsibilities of an Operating System

- Manages CPU
- Manages memory (RAM)
- Manages storage devices
- Controls input and output devices
- Runs applications
- Provides security

---

# What is Unix?

Unix is one of the oldest operating systems. It is known for its stability, security, and reliability. Many modern operating systems are based on Unix principles.

### Features of Unix

- Stable
- Secure
- Multi-user
- Multi-tasking
- Powerful command line

---

# What is Linux?

Linux is a free and open-source Unix-like operating system created by **Linus Torvalds** in 1991.

It follows Unix principles but is freely available for everyone to use, modify, and distribute.

Linux is widely used in:

- Personal computers
- Servers
- Android devices
- Cloud computing
- Embedded systems
- Supercomputers

---

# Why was Linux Created?

Unix was powerful and stable but had several limitations.

- Proprietary software
- Expensive licensing
- Limited accessibility

To overcome these limitations, Linus Torvalds developed Linux as a free Unix-like operating system.

---

# Why Linux is Popular

Linux has become one of the most widely used operating systems because it is:

- Free to use
- Open source
- Secure
- Stable
- Highly customizable
- Reliable

---

# What is Open Source?

Open source means the source code is publicly available.

Anyone can:

- View the source code
- Learn from it
- Modify it
- Improve it
- Share improvements with others

---

# Linux Kernel

The Kernel is the core component of Linux.

It acts as a bridge between hardware and software.

### Functions of Kernel

- Manages CPU
- Manages RAM
- Controls hardware devices
- Allocates system resources
- Runs processes

Without the kernel, Linux cannot function.

---

# Linux Distribution (Distro)

A Linux Distribution is a complete operating system built around the Linux Kernel.

A distribution generally contains:

- Linux Kernel
- System utilities
- Software packages
- Desktop Environment
- Package Manager

### Popular Linux Distributions

- Ubuntu
- Debian
- Fedora
- Kali Linux
- Arch Linux

Although distributions look different, they all use the Linux Kernel.

---

# Why are there Different Linux Distributions?

Different users have different requirements.

For example:

- Ubuntu → Beginner friendly
- Debian → Stable
- Fedora → Latest technologies
- Kali Linux → Cybersecurity and Penetration Testing

---

# Linux vs Windows

| Linux | Windows |
|--------|----------|
| Free | Paid |
| Open Source | Closed Source |
| Highly Customizable | Limited Customization |
| Secure | More common malware target |
| Powerful Terminal | Command Prompt / PowerShell |
| Widely used in Servers | Mostly Desktop Usage |

- Mouse
- Icons
- Windows

- Menus

- Windows Desktop

---

## CLI (Command Line Interface)

CLI allows users to interact with the computer by typing commands.

Example:

- Linux Terminal

- Faster
- Uses fewer resources
- Easy to automate
- Greater control over the system

# Automation

Automation means making the computer perform repetitive tasks automatically without manual intervention.

### Benefits

- Saves time
- Reduces human errors
- Improves efficiency
- Performs repetitive tasks automatically

Automation is widely used in:

- Servers
- Cloud Computing
- System Administration
- Cybersecurity
- Backups

# Why Linux is Used in Servers

Linux is widely used on servers because it is:

- Stable
- Secure

# Linux in Cloud Computing

Cloud providers prefer Linux because it:

# Linux in Cybersecurity

Linux is widely used in cybersecurity because it provides:

- Strong permission system
- Powerful security tools
- Deep system control
- Excellent networking capabilities

---

# Linux in Digital Forensics

Linux is commonly used in Digital Forensics because it provides:

- Better disk analysis
- File system investigation
- Memory analysis
- Evidence preservation
- Recovery of deleted files

It is trusted by forensic investigators for analyzing digital evidence.
